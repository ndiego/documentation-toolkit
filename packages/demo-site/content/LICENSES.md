# Media licences

Every file in `media/` is listed here. Add a row when you add a file; `shots doctor` (planned) will flag files
without a row.

Photos come from the [WordPress Photo Directory](https://wordpress.org/photos/). Every photo there is released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), so attribution is not required, but we record it
anyway. The files were downloaded on 2026-10-09 at the directory's 2048 px size, then resized to at most 2000 px on
the long edge and re-encoded as JPEG (sharp, mozjpeg) with metadata stripped. Nothing else was edited.

# Notes

Notes let editors and reviewers discuss a post inside the editor, attached to the block they are about. A note starts
from the block's Options menu.

![A Paragraph block's Options menu open on the editor canvas, with the Add note item outlined.](../assets/screenshots/notes/add-note.webp)

Choosing **Add note** opens a note box next to the block. Type the note and choose **Add note** to save it.

![A note being written on a Paragraph block, with the note box open and a sentence typed but not yet added.](../assets/screenshots/notes/writing-note.webp)

Once a post has notes, the **All notes** button in the top bar opens the Notes sidebar, where every thread is listed
with its replies. Resolved threads move to the bottom of the list.

![The post editor with the Notes sidebar open, showing an open note with a reply and a resolved note below it.](../assets/screenshots/notes/notes-sidebar.webp)

![The Notes sidebar, with the resolved note's Marked as resolved entry outlined.](../assets/screenshots/notes/resolved-note.webp)

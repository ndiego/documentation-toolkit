# Table block

The Table block adds a table with a header row, body rows and an optional footer.

![A Table block on the editor canvas, selected, showing a three-column table of walking routes.](../assets/screenshots/table-block/canvas.webp)

## Toolbar

Use **Edit table** to insert or delete rows and columns.

![The Table block toolbar, with the Edit table button outlined.](../assets/screenshots/table-block/toolbar.webp)

## Styles

The **Styles** tab switches between the **Default** and **Stripes** styles.

![The Table block's Styles tab in the block inspector, where the Default and Stripes styles are chosen.](../assets/screenshots/table-block/styles.webp)

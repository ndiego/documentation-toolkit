# Image block

The Image block places a single image in your content, with an optional caption.

![An Image block on the editor canvas, selected, showing a photo of a lake at sunrise with a caption below it.](../assets/screenshots/image-block/canvas.webp)

## Toolbar

Select the block to show its toolbar. Use **Replace** to swap the image for another one from your media library or
a URL.

![The Image block toolbar, with an arrow pointing at the Replace button.](../assets/screenshots/image-block/toolbar.webp)

## Settings

The **Settings** tab controls how the image is sized and linked. **Resolution** picks which generated size of the
image is used.

![The Image block's Settings tab in the block inspector, with the Resolution setting outlined.](../assets/screenshots/image-block/settings.webp)

## Alternative text

Describe the image for people who cannot see it. The field is on the **Content** tab of the block inspector.

![The Image block's Content tab in the block inspector, where the alternative text field lives.](../assets/screenshots/image-block/alt-text.webp)

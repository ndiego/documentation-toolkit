# Gallery block

The Gallery block displays several images in a grid.

![A Gallery block on the editor canvas, selected, showing three landscape photos in a row.](../assets/screenshots/gallery-block/canvas.webp)

## Settings

**Columns** sets how many images sit side by side. The images crop to a uniform size unless you turn off
**Crop images to fit**.

![The Gallery block's Settings tab in the block inspector, with the Columns control outlined.](../assets/screenshots/gallery-block/settings.webp)

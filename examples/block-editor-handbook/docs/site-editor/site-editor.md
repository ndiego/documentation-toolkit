# Site editor

The site editor is where you edit templates, template parts, styles and navigation for a block theme.

![The site editor with the Ipsum theme, showing the home template on the canvas and the navigation sidebar.](../assets/screenshots/site-editor/home.webp)

## Styles

Open **Styles** to change colors, typography and layout for the whole site.

![The site editor's Styles view.](../assets/screenshots/site-editor/styles.webp)
